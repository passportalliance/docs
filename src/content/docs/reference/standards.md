## Relevant Standards and Frameworks

| Standard | Relevance to APIS |
| --- | --- |
| OAuth 2.0 (RFC 6749) | Authorization framework foundations |
| OpenID Connect 1.0 | Discovery and identity metadata interoperability |
| JWT (RFC 7519) | Token and claims representation |
| W3C DID Core | Decentralized identifier model context |
| RFC 8785 | JSON canonicalization for robust signing |
| NIST SP 800-63 | Digital identity assurance guidance |
| ISO/IEC 27001 | Security management system baseline |

## APIS Design Position

APIS composes existing identity and cryptographic standards for machine-actor delegation, rather than replacing mature IAM primitives.

## Governance Position

Passport Alliance™ governance follows a familiar pattern used by successful standards ecosystems:

- technical specification
- profile catalog and reference artifacts
- reference implementation
- conformance suite
- transparent membership and change process
- public trust signaling through registry and policy
