## Canonical Terms

| Term | Meaning |
| --- | --- |
| `Principal` | Issuing or owning legal or organizational identity accountable for an agent and its authority |
| `Delegate` | Scoped authority granted by a principal to a software actor |
| `Agent Passport Profile` | Issuance recipe or credential class definition |
| `Agent Passport™` | Minted credential instance issued to a concrete agent |
| `Registry Entry` | Public verification record published by the registry surface |
| `Proof Artifact` | Evidence package, DOI record, signed artifact, or reference proof used to support verification |
